# AR Vault

GitHub Pages iPhone AR object browser. Searches the public 3DTomb REST API, previews compatible remote 3D assets, and exposes USDZ results to Apple's AR Quick Look.

## Deploy

Upload `index.html`, `style.css`, and `app.js` to a GitHub repository. Enable GitHub Pages in Settings > Pages. Open the resulting HTTPS URL in iPhone Safari.

## Notes

No models are stored in the repository. The app requests remote model metadata and assets from the catalog. GLB assets preview in the browser. USDZ assets can use Apple's AR Quick Look.

Check each asset's license before reuse.
